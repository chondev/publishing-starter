# 샘플 확인 결과

## 신규 구축 기준 반영 — 2026-11-17

현재 기준은 HTML 6개와 정적 자원 24개다. 아래 초기 기록의 4개·5개 화면, 설치 폰트만 사용하는 설명과 처리 방식은 각 버전의 이력이며 현재 상태와 구분한다.

### 변경 범위

- 모든 반응형 배치를 모바일 기본 → `min-width` 확장으로 변경. 독립형 페이지와 공통 레이아웃 분리는 유지.
- Pretendard v1.3.9 공식 WOFF2 서브셋 400·500·600·700·800을 로컬 포함. `fonts.css`, 시스템 대체 글꼴, `font-display: swap`, 출처·라이선스 추가. 원본 글꼴 파일은 변형하지 않음.
- 필드 매크로의 오류·값·autocomplete 인자, 오류 요약, 입력별 오류 연결·해제, 버튼과 Enter의 공통 submit 처리 추가. 데모의 전송·저장 기능은 없음.
- UI 화면에 폰트 굵기·수동 선택 탭·비동기 로딩/성공/실패/재시도·caption/scope가 있는 스크롤 표 추가.
- `/accessibility/`에 정보/장식 이미지·입력 그룹·링크/버튼·색상 외 상태·부분 언어 예시 추가. 사이트 메뉴에서 접근 가능.
- README에 구성 의도와 링크, `STYLE_GUIDE.md`에 퍼블리셔용 기준·컴포넌트 사용법·검증 절차 작성.
- 의존성·package.json·잠금 파일 변경 없음. 기존 서비스 작업 사본은 수정하지 않음. 대상은 SVN 작업 사본이 아닌 독립 폴더.

### 남은 검증과 사용 시 주의

- HTML Validator·axe 전체 검사, 전체 색상/상태 대비 측정, 실제 화면낭독기의 이름·상태 발화, iOS·Android 실기기 시험은 이번에도 미수행.
- 실제 200% 텍스트 확대·400% 브라우저 확대는 미수행. 루트 글자 크기와 뷰포트 변경 시험으로 대체 완료 처리하지 않음.
- 단순 문서 가로 넘침 검사는 잘림·겹침·읽기 순서·보조기술 사용성을 모두 보장하지 않음.
- 서브셋 밖 문자·실제 개인정보 자동완성·서버 오류·실제 API·기존 JSP 이관은 실제 콘텐츠와 환경에서 별도 검증.
- 폰트 차단 컨텍스트의 네트워크 실패 로그와 최초 서버 기동 전 연결/404 오류는 의도한 폴백 시험 또는 준비 구간 기록이며, 정상 기능 실행 중 pageerror 결과와 구분.
- SVN Commit·Merge·배포·외부 전달·Notion 작업은 수행하지 않음.

## 미수행·제한

- HTML Validator·axe 전체 검사, 색상 대비의 전 조합 측정, 전체 접근성 심사 미수행.
- 실제 iOS·Android·화면낭독기, 200% 텍스트 확대·400% 브라우저 확대 시험 미수행. 320px 뷰포트 확인과 별개다.
- 신청 예시는 서버 전송·영속 저장 기능이 없다. 실제 업무 처리·개인정보 수집·JSP·세션·DB·운영 배포는 범위 밖이다.
- 샘플 CSS의 상태 예시는 기본 시작점이며, 실제 서비스에서 필요한 처리 중·오류·비활성 등 모든 조건을 완성한 디자인 시스템이 아니다.
- minify·번들링·gzip은 미구성. 현재는 읽기 좋은 원본 CSS/JS를 그대로 복사한다.
- 공통 수정은 src에서 수행하고 dist는 다시 생성한다. 직접 dist를 수정하면 다음 빌드에서 덮어써진다.
- 브라우저 자동 반영은 전체 새로고침 방식이므로 입력값·열린 UI 상태를 보존하지 않는다.
- SVN Commit·Merge, 배포, 외부 전달, Notion 수정은 수행하지 않았다.
